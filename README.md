# 🧪 Автоматизация UI-тестирования (Selenium + Pytest + Allure)

Репозиторий содержит автоматизированные UI-тесты для двух веб-ресурсов, написанные на **Python** с использованием паттерна **Page Object Model (POM)**:
1. **Калькулятор с задержкой** — проверка математических вычислений при долгой обработке данных.
2. **Интернет-магазин Swag Labs** — сквозной (`End-to-End`) сценарий покупки товаров.

Все тесты снабжены строгими аннотациями типов, docstring-документацией, а также подробно размечены шагами и метаданными **Allure Report**.

---

## 🛠️ Подготовка окружения

### 1. Установка зависимостей Python
Убедитесь, что ваше виртуальное окружение активировано (`.venv`), и установите необходимые библиотеки:
```bash
pip install selenium pytest allure-pytest
```

### 2. Установка Allure CLI в операционную систему
Для сборки веб-отчетов на **Windows** требуется консольная утилита Allure. Быстрее всего установить её через встроенный пакетный менеджер (запустите терминал от Администратора):
```powershell
winget install Qameta.Allure
```
> [!NOTE]
> После установки Allure CLI обязательно перезапустите PyCharm, чтобы терминал обновил свои пути и «увидел» новую команду.

---

## 🚀 Запуск тестов и работа с отчетами

В проект добавлен автоматический скрипт **`run.ps1`**, разработанный специально для среды Windows PowerShell. Он берет на себя весь цикл очистки папок, запуска тестов, сохранения истории графиков трендов и генерации отчета.

### Вариант А. Автоматический запуск через скрипт (Рекомендуется)

Выполните команду в терминале PowerShell для полного прогона тестов и автоматической генерации графического отчета:
```powershell
powershell -ExecutionPolicy Bypass -File .\run.ps1
```
> [!TIP]
> Данный скрипт автоматически соберет данные, подтянет историю предыдущих запусков (для графиков трендов), сформирует отчет в папке `final-report` и **сам откроет его в вашем браузере по умолчанию**.

### Вариант Б. Ручной запуск по шагам

Если вы хотите выполнить команды вручную, следуйте этой инструкции:

1. **Формирование сырых результатов тестов:**
   Запустите `pytest` с указанием целевой папки для хранения промежуточных JSON и XML данных:
   ```bash
   python -m pytest lesson_10/ --alluredir=allure-results
   ```

2. **Просмотр отчета без генерации физических файлов (быстрый превью):**
   Эта команда создает временный локальный веб-сервер и автоматически открывает интерактивный отчет в браузере:
   ```bash
   allure serve allure-results
   ```

3. **Сборка полноценного статического HTML-отчета:**
   Если вам нужно скомпилировать готовые веб-страницы в конкретную папку:
   ```bash
   allure generate allure-results -o final-report --clean
   ```
